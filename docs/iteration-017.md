# Iteration 017 — original combat and magic formula research

User decision: preserve the original combat/magic formulas as the baseline, using clean typed implementation. Preserve gameplay-relevant integer order, thresholds and random intervals; keep offsets/globals/storage sentinels out of runtime state. Deferred remake balance features remain separate.

Read-only analysis of the same supplied executable recovered a single-weapon character attack/swing budget, weighted class-history combat experience, ordinary player casting risk/color arithmetic, single-roll failure/backfire intervals, Power Cast integer scaling, base effect strength and a common resistance-reduction helper. The exact inspected SHA256 and instruction addresses are recorded in [physical evidence](original-combat-formulas.md) and [magic evidence](original-magic-formulas.md). Original files were not executed or redistributed. Static local-path evidence is not an interactive original-game comparison.

Added independent `core/Rules/OriginalCombatRules.cs` and `OriginalMagicRules.cs`. They take semantic values and resolved draws and return calculations, with no Godot or GameState dependency. The character attack branch uses integer operations, resolving the guide's 599.9999 discrepancy at Rogue level 25. Casting thresholds above 100 remain intact before computing backfire bands. Resistance uses two exclusive random bounds, which differ at even positive pressure, and subtracts a floored reduction rather than flooring the remaining fraction.

Scope remains explicit: free other hand for physical budgets; caller-resolved book/realm skills and class term for ordinary casting; external source/context and spell-specific modifiers excluded. Base effect strength is not a complete spell resolver, and resistance takes a resolved strength rather than assuming twice caster level. Original 9999 sentinel effects require an explicit higher-level representation. The live sentinel, fixture spells and saves are unchanged; original actor attributes/class history, hit/penetration, conditions, damage/healing paths and their state integration still need reconstruction.

Validation: 512 portable C# checks including mobile gestures; 513 with private spell scenarios covering 118 positive-level records at powers 1–7 (826 metadata scenarios with supplied skill/level fixtures, not eligibility assertions). 25 Python tests pass; warning-free client build, real-data Godot gameplay smoke and synthetic mobile smoke pass. Public tests use synthetic values only, including exact attack/swing boundaries, class groups, all d100 outcomes for 300 thresholds, resource-free deterministic calculations, Power Cast rounding and resistance extremes. No original database rows, disassembly dumps or binaries are committed.
