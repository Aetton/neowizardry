# Iteration 024 — projectile aim point and pending launch

Reconstructed the aim perturbation helper `0x5454C0`: a perpendicular basis, angle draw, distance reduction of the supplied score, Standard/Alternate spread envelopes, and a separate d100 selecting signed deviation. This modifies the point toward which a projectile is created; it is not a final hit/miss probability. The profile flag comes from resolved actor fields whose meaning is still being traced, so it is not labelled blindness or mapped to a class/weapon assumption.

Added `OriginalProjectileAim` with typed engine-independent coordinates, scalar breakdown and deterministic draw inputs. Preserved angle-before-sub-unit-return draw order, signed/truncated score arithmetic, the inner 95-roll cap, the actual outer-branch denominator, negative deviation and the exact Y-axis zero-basis case. The pure calculation uses double precision and finite/overflow guards. It reconstructs formulas without emulating x87/float storage; bit-exact parity or original collision equivalence is not claimed.

Added ordinary aimed `OriginalProjectileAttack.Launch` and serializable `AimedProjectileLaunch`, combining pending resource state with an aim snapshot without spending ammo. A caller can persist the complete flight and later supply its actual collision to the existing penetration/damage/resource completion. The wrapper explicitly rejects native score 9999, whose separate caller path bypasses spread. Native direct-contact and no-spread eligibility are not invented.

Validation: 1020 portable C# checks including gestures (65 added), 1027 with the private 819-item catalog, 1021 with private spell metadata/power scenarios (826 combinations, not actor eligibility). 27 Python tests pass. Client build has zero warnings/errors. Real-data Godot gameplay and synthetic mobile smokes pass. Tests cover analytic cardinal/oblique directions, all 360 integer angles in one geometric sweep, transverse/radial invariants, score/distance boundaries, nonpositive-score branches, alternate signed deviation, sub-unit and exact-unit draw plans, vertical/coincident vectors, invalid/overflowing inputs, full aimed-flight serialization and launch → caller-resolved contact/miss → damage/resource completion.
