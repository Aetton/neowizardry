All 150 records and description hashes equal the earlier import; only description provenance changes from archived to extracted-loose source. The newly attached Archive.tar.gz contains notes, not game databases. A private catalog package is delivered separately with backup-preserving Windows installation; original rows are not committed or published in GitHub releases.

Frost and Energy Blast now resolve success/fizzle/backfire in the shared round executor. Ordinary completed attempts pay base cost × selected power. Backfire redirects their damage and resistance to the caster. Heal Wounds selects a living party member, uses imported 4d4 × power plus full integer Power Cast, clamps to missing HP and spends Divine mana; full HP skips healing dice but still pays. Its native classifier admits fizzle, not backfire. Preview uses the same preparation without RNG. Dead casters and unavailable healing targets cannot spend mana. Native reactions/conditions/progression and spatial delivery remain outside this neutral training subset; see [evidence](original-magic-formulas.md).
