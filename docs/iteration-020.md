# Iteration 020 — ordinary physical damage and connected melee calculation

Corrected an error in iteration 019: BAR must include class-history combat experience E, not load contribution L. The previous trace confused local stack +0x14 with +0x10. The producer at 0x4EE3AD–0x4EE3B6 and read at 0x4EE51C establish the correct term. Fixed code, replaced incorrect test expectations, added level/load contrast and independent overflow regressions, and corrected the current formula documentation with an explicit erratum in the historical 019 report. Passing old tests did not prove the old formula.

Added primary-hand STR/DEX/SEN/hand-load contributions, explicit Full/Half/None Strength policy and an original-data adapter for prepared weapon/ammunition inputs. Legacy icon/category conventions remain isolated at this boundary. Launcher dice come from resolved ammunition; launcher constant contributes a percentage. The Strength exception table jumps over both Strength contributions for selected ranged categories, including Omnigun, rather than applying full Strength. This preserves the baseline and does not implement the deferred Gadgeteer rework.

Added shared physical damage arithmetic: repeat the complete signed-constant dice expression with independent draws, scale by hand/effect percentages with +50 rounding and signed truncation, floor at one, then apply resolved target absorption with its own rounding and floor at zero. Original feedback-only RNG is not coupled to this math module. Repetition eligibility, target absorption derivation and later special effects remain external gates.

Added `OriginalMeleeStrike.Resolve`: a connected neutral weapon-melee calculation with no fumble redirection (untargeted hit score >=100), one shared contact/penetration d100, ordinary automatic outcomes 1–5 and natural misses 96–100. A miss or failed penetration takes no damage draws. Neutral Berserk re-rolls the full damage expression twice. This calculation is not a whole combat round or a replacement for the live fixture battle; actor/target validation, special contexts, low-score fumbles, projectile delivery, resource spending, HP mutation and original save data still need integration.

Corrected item damage constant import from unsigned WORD to signed WORD at +0x4A. Integer JSON and schemas 2/3 remain; old exports with unsigned-only values above 32767 require regeneration. All 819 supplied rows keep identical values, and synthetic fixtures cover the signed limits. The experimental imported-weapon hit now floors its raw roll at one to prevent negative constants from healing the enemy. Negative constants display with a minus sign. Unarmed fixture Power remains unchanged.

Validation: 629 portable C# checks including gestures; 636 with the private 819-item catalog; 630 with private spell metadata/power scenarios (826 combinations, not actor eligibility). 27 Python tests pass. Client build has zero warnings/errors after restoring local Godot packages from the retained tool bundle. Real-data Godot gameplay smoke and synthetic mobile smoke pass. New checks cover the corrected BAR, combined launcher/ammo accuracy, Strength suppression and halving, independent repeated dice, two-stage rounding, damage floors/absorption, every shared d100 outcome, unused-roll rejection, unsupported redirection/projectile paths, signed imports and overflow. Static reconstruction is not an original-game execution comparison.
